
# TrpgMaps

跑团（TRPG）地图投屏工具。DM 在自己电脑上打开本程序，把地图投到大屏 / 电视上，
玩家用手机扫码打开网页就能看到同一张地图 —— 网格、缩放、旋转、底图全部同步。

**当前版本：v1.0.2（32 位版）**

- 源码：<https://github.com/starnight-dirt/TrpgMaps>　（镜像：<https://gitee.com/starnight-dirt/TrpgMaps>）
- 下载：仓库的 [**Releases**](https://github.com/starnight-dirt/TrpgMaps/releases) 页面

## 一、最低配置要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 7 SP1 及以上（含 Windows 8 / 8.1 / 10 / 11） |
| 系统位数 | 32 位、64 位都可以（程序本身是 32 位，在两种系统上都能跑） |
| 运行库 | **不需要安装任何东西**。Windows 7 用自带的 .NET Framework 3.5，Windows 8 及以后会自动使用系统自带的 .NET Framework 4.x |
| 内存 | 1 GB 以上 |
| 硬盘 | 约 10 MB（解压后约 5.2 MB，下载包约 5 MB） |
| 显示 | 推荐 1366×768 及以上；窗口最小可缩到 800×480 |
| 网络 | 需要一台手机能连上的局域网（同一 Wi-Fi / 同一路由器）。DM 端与玩家端必须在**同一个局域网**内 |

玩家端（手机 / 平板）：

| 项目 | 要求 |
| --- | --- |
| 系统 | iOS 12+ / Android 7+ |
| 浏览器 | 系统自带浏览器或 Chrome / Safari 等主流浏览器即可，无需安装 App |
| 网络 | 与 DM 端在同一个局域网 |

> 注：本程序不联网、不上传任何数据。局域网内的地图与绘图同步全部发生在同一台机器上；
> 只有「检查更新」这一个功能会访问网络。

## 二、安装与启动

### 方式 A：安装版（推荐）

1. 下载 `TrpgMaps_v1.0.2_win32_installer.exe`，双击运行。
2. 第一页选安装目录（默认是 `C:\Program Files (x86)\TrpgMaps`），点「下一步」。
3. 第二页勾选需要的快捷方式（桌面 / 开始菜单 / 任务栏，默认全选），点「安装」。
4. 首次运行如果 Windows 弹出「是否允许 TrpgMaps 通过防火墙」，**请务必点「允许」**，
   否则手机连不上（详见第四节）。
5. 卸载：**设置 → 应用 → 已安装的应用**（Windows 7 是：**控制面板 → 程序和功能**）里
   找到 TrpgMaps，点「卸载」即可。卸载时可以选择保留地图与绘图数据。

### 方式 B：便携版

1. 下载 `TrpgMaps_v1.0.2_win32_portable.zip`。
2. 解压到**任意可写目录**（例如 `D:\TrpgMaps`，或直接解压到 U 盘）。
   ⚠️ 不要解压到 `C:\Program Files` 这类受保护目录 —— 便携版没有安装程序去放开写权限，
   上传底图和保存绘图都会失败。
3. 双击里面的 `TrpgMaps.exe`。
4. 卸载：直接删掉整个文件夹即可（程序不会往其它地方写东西，
   注册表里也不会有记录）。

两种方式的功能完全一样。区别只是：安装版会把卸载信息写进系统、并创建快捷方式；
便携版是全绿的，换台电脑整个文件夹拷过去就能用。

## 三、使用方法

### DM 端（你的电脑）

1. 双击 `TrpgMaps.exe`。程序会**全屏无边框置顶**打开，适合直接投到电视 / 大屏。
2. 左侧侧边栏从上到下是：

   | 按钮 | 作用 |
   | --- | --- |
   | 展开 | 展开 / 收起侧边栏（展开后会显示文字标签） |
   | 地图设置 | 选底图、调网格大小、选网格颜色、旋转角度、导入自己的图片 |
   | 网络 | 查看**房间号**、玩家地址与二维码、设置**房间密码**、设置端口、放行防火墙、管理在线玩家 |
   | 绘图 | 在地图上盖地形 / 实体 / 物品（左上角浮窗，可拖动） |
   | 全屏 | 切换全屏 / 窗口 |
   | 关于 | 作者信息、版本号、检查更新 |

3. 点「网络」，会出现一个**房间号**、一个**玩家地址**和一个**二维码**。
   - **房间号每次打开程序都会换一个新的**（8 位数字）。玩家地址里就带着它：
     `http://192.168.1.100:20020/房间号/player`。所以每次开新一局，
     直接让玩家扫**新的**二维码就行。
   - 想让这一局"只有拿到号的人能进"？在「房间密码」里填一个密码再点
     「保存密码并刷新地址」，二维码和地址会**自动带上密码** ——
     扫码进来的玩家不用手打密码，登录时只填名字。
     留空再保存就是取消密码。
4. 点「地图设置」→「导入图片」可以换成自己的地图。
   支持 PNG / JPG / GIF / BMP / WebP，直接把图片文件拖进窗口也行。
5. 点「绘图」可以往地图上铺地形（草地、水域、火焰……）、放实体与物品。
   面板里的「清空本类」只清除当前选中那一类，「清空全部」才会清掉所有覆盖层。

### 玩家端（手机 / 平板）

1. 连上**和 DM 同一台路由器**的 Wi-Fi（不是手机流量）。
2. 用相机 / 微信扫 DM 屏幕上那个二维码，或直接在浏览器里输入 DM 端显示的玩家地址
   （形如 `http://192.168.1.100:20020/12345678/player`）。
   **没有二维码、或者扫码坏了**？让玩家打开 `http://ip:端口/join`，手填
   **房间号 + 名字**（房间设了密码就再填上密码）也能进；填错了会明确告诉他
   是"房间不存在"还是"房间密码错误"。
3. 打开后就能看到地图，DM 端的一切改动都会实时同步过来。
   网页是只读的，玩家不能改动地图。
4. 玩家加入后，会出现在 DM 端「网络」面板的在线列表里。
5. 想退出？**屏幕右下角那个圆形按钮** → 「退出房间」。
   退出后 DM 和其他玩家都会看到一条「**xxx 离开了房间**」的提示，
   本机也会把身份信息清干净（重新进来只需再填一次名字）。
   DM 重启程序换了房间号时，玩家页面会**自己发现并重新加入新房间**，不用重新扫码。

## 四、连不上？先看这里

手机打不开玩家页面，**九成以上是 Windows 防火墙的问题**，而且症状很有迷惑性：
DM 端一切正常、地址也对、二维码也能扫，手机就是一直转圈打不开。

处理办法：

1. 打开 TrpgMaps 的「网络」面板，看「防火墙：」那一行。
   如果它提示被阻止，直接点下面的 **「放行防火墙（需管理员确认）」** 按钮，
   在弹出的是否允许提示里点「是」，然后重试。
2. 程序目录里有一个 **`放行防火墙.bat`**，右键「以管理员身份运行」也可以（同样会弹一次确认）。
   便携版就在解压出来的文件夹里，安装版在安装目录里。
3. 首次启动时如果 Windows 弹出「是否允许 TrpgMaps 通过防火墙」——
   这个提示框有时会被程序的全屏界面挡住，请**先最小化 / 切出去找一下**，并点「允许」。

> 为什么会被挡：本程序默认全屏置顶，而 Windows 的授权提示是普通窗口，
> 会被压在底下。如果被随手关掉，Windows 会记住一条永久阻止规则，以后再也不会问你。
> 所以程序在启动时会主动检查，被挡就直接提示并提供一键修复。

其它可能原因：

- **手机和电脑不在同一个局域网**（手机开的是流量，或连了访客 Wi-Fi）。
  请确认两边的 IP 前三段一致（比如都是 `192.168.1.x`）。
- **路由器开了「AP 隔离 / 客户端隔离」**，同一 Wi-Fi 下的设备互相不能通信。
  到路由器设置里关掉它，或换一个 Wi-Fi。
- **端口被占用**：到「网络」面板把端口改成别的（比如 5001）再保存重开。
- **校园网 / 公司网**：这类网络通常禁止设备之间互访，建议自己开热点。

## 五、更新

- 程序启动几秒后会自动检查一次是否有新版本；也可以点侧边栏最底部的
  **「关于」→「检查更新」** 手动检查。
- 发现有新版本时会弹窗，三个选项：
  - **更新** —— 自动下载并安装（便携版只替换程序文件；安装版还会顺带修正注册信息）；
  - **下次一定** —— 这次先不更新，下次启动还会提醒；
  - **不再提示** —— 不再提醒这个版本，后续更新的版本仍会提示。
- 更新源优先使用 **Gitee**，失败时自动切换到 **GitHub**。
- 也可以随时到仓库的 Releases 页面手动下载安装包覆盖安装。

## 六、常见问题

**Q：程序打不开 / 一闪而过？**
A：看程序目录下的 `app.log`，里面记录了失败原因。

**Q：地图是黑的？**
A：v1.0.0 起已支持 WebP。如果你用的是自己导入的图片，请确认扩展名是
`.png / .jpg / .jpeg / .gif / .bmp / .webp` 之一。

**Q：网格和底图对不齐？**
A：网格的格子大小是按厘米算的，与实际打印尺寸无关。
在「地图设置」里拖动滑块调整「每格厘米数」即可让格子对上底图上的格子。

**Q：能同时给多个人用吗？**
A：可以。局域网内任意数量的手机 / 平板都能同时连上来看同一张地图。

**Q：会把我的地图上传到网上吗？**
A：不会。程序没有任何联网上传行为，地图只在你自己的电脑上。
唯一的网络请求是「检查更新」。

**Q：卸载后我的地图和绘图还在吗？**
A：安装版的卸载程序会问你是否保留 `maps` 目录与 `drawing.json`，
选择保留就会留在安装目录里。便携版删除文件夹即可，注意先备份。

## 七、版本历史

### v1.0.2

- **每个 DM 实例有自己的房间号**：每次打开程序都会生成一个新的 8 位房间号，
  玩家地址从 `ip:端口/player` 变成 `http://ip:端口/房间号/player`。
  它的用处是把"身份"钉在某一个房间上 —— DM 重启之后房间号会换，
  玩家页面能立刻看出"这一局换人了"，自动向旧房间告辞并以新玩家加入。
- **房间密码（可选）**：在「网络」面板里填一个密码即可；地址与二维码会自动带上它，
  玩家扫码进来**不用手打密码**，登录时只填名字。房间没设密码时行为与以前完全一样。
- **退出房间**：玩家页右下角新增一个圆形悬浮按钮（跟着屏幕走，转屏后自动回到右下角；
  可拖到任意位置），点开是「退出房间」。退出后服务器会把这名玩家从名册里删掉
  （令牌一起作废），DM 与其他玩家的屏幕上方会弹出一条
  「**xxx 离开了房间**」的胶囊提示。房间已经离线时，退出同样生效（以本地为准）。
- **更安全的地址接口**：带房间密码的 `/api/network` 现在只接受本机请求，
  不会再把这个地址告诉局域网里的其他人。
- **默认端口改成 20020**（原来是 5000）：5000 经常被别的程序占，也常被 Windows
  **自己保留**给 Hyper-V / WSL / Docker（报错是"以一种访问权限不允许的方式…"，
  **杀进程、放行端口都没用**）；8080 这类端口在国内会因"未备案域名"被运营商阻断，
  所以也不用。
- **端口被占就自己换**：启动时按「20020 → 往后顺延 9 个 → 随机」找一个真能绑上的端口，
  玩家地址与二维码自动跟着变（手填的端口不会被换掉，起不来会退回原端口并说明原因）。
- **新增 `/join` 页**：手填房间号的登录入口（房间号 / 玩家名 / 密码三个框）——
  房间号不对提示「房间不存在」、密码不对提示「房间密码错误」。

### v1.0.1

- **安装 / 卸载程序重做**：窗口改成圆角卡片、界面全部自绘 —— 这样在 Windows 7 和在
  Windows 10 / 11 上长得完全一样；安装选项变成可点选的胶囊，选中项右侧带绿色对号。
  安装程序与卸载程序也各自有了定制图标，任务栏里不再是空白图标。
- **修掉安装 / 卸载程序的三处毛病**：点「下一步」会直接开始安装（没机会翻到第二页）、
  卸载窗口不是圆角、卸载窗口的按钮跑到窗口外面看不见。
- **地形素材改用 WebP**：程序自带的 14 张地形素材由 PNG 换成 WebP，
  安装后占用从约 33.6 MB 降到约 5.2 MB，下载包也从约 33 MB 降到约 5 MB。
- **修复素材预览全黑**：地形素材换成 WebP 后，地图上显示正常，但「绘图」面板里的
  素材列表缩略图全是黑的 —— 已修好，现在 14 张素材都能正常预览。
- **升级更安全**：升级包替换素材时不会「只删不补」，不会把某个素材目录清空。

### v1.0.0

- 首个正式发布版本。
- 支持自定义底图（PNG / JPG / GIF / BMP / WebP）、网格大小与颜色、旋转、缩放。
- 手机 / 平板扫码加入，实时同步地图与绘图。
- 地形 / 实体 / 物品三层绘图，支持严格与宽泛两种选区方式。
- 内置更新检测（Gitee 优先，GitHub 兜底）。
- 提供安装版与便携版两种发布形式。
