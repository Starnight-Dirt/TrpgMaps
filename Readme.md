# TrpgMaps

跑团（TRPG）地图投屏工具。DM 在自己电脑上打开本程序，把地图投到大屏 / 电视上，
玩家用手机扫码打开网页就能看到同一张地图 —— 网格、缩放、旋转、底图全部同步。

**当前版本：v1.0.0（32 位版）**

- 源码：<https://github.com/starnight-dirt/TrpgMaps>　（镜像：<https://gitee.com/starnight-dirt/TrpgMaps>）
- 下载：仓库的 [**Releases**](https://github.com/starnight-dirt/TrpgMaps/releases) 页面
- 作者：[starnight-dirt](https://github.com/starnight-dirt)

## 一、最低配置要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 7 SP1 及以上（含 Windows 8 / 8.1 / 10 / 11） |
| 系统位数 | 32 位、64 位都可以（程序本身是 32 位，在两种系统上都能跑） |
| 运行库 | **不需要安装任何东西**。Windows 7 用自带的 .NET Framework 3.5，Windows 8 及以后会自动使用系统自带的 .NET Framework 4.x |
| 内存 | 1 GB 以上 |
| 硬盘 | 约 40 MB（解压后约 33.6 MB，下载包约 33 MB） |
| 显示 | 推荐 1366×768 及以上；窗口最小可缩到 800×480 |
| 网络 | 需要一台手机能连上的局域网（同一 Wi-Fi / 同一路由器）。DM 端与玩家端必须在**同一个局域网**内 |

玩家端（手机 / 平板）：

| 项目 | 要求 |
| --- | --- |
| 系统 | iOS 12+ / Android 7+ |
| 浏览器 | 系统自带浏览器或 Chrome / Safari 等主流浏览器即可，无需安装 App |
| 网络 | 与 DM 端在同一个局域网 |

> 注：本程序不联网、不上传任何数据。局域网内的地图与绘图同步全部发生在同一台机器上；
> 只有「检查更新」这一个功能会访问网络。

## 二、安装与启动

### 方式 A：安装版（推荐）

1. 下载 `TrpgMaps_v1.0.0_win32_installer.exe`，双击运行。
2. 选择安装目录（默认是 `C:\Program Files (x86)\TrpgMaps`），
   勾选需要的快捷方式（桌面 / 开始菜单 / 任务栏，默认全选），点「开始安装」。
3. 首次运行如果 Windows 弹出「是否允许 TrpgMaps 通过防火墙」，**请务必点「允许」**，
   否则手机连不上（详见第四节）。
4. 卸载：**设置 → 应用 → 已安装的应用**（Windows 7 是：**控制面板 → 程序和功能**）里
   找到 TrpgMaps，点「卸载」即可。卸载时可以选择保留地图与绘图数据。

### 方式 B：便携版

1. 下载 `TrpgMaps_v1.0.0_win32_portable.zip`。
2. 解压到**任意可写目录**（例如 `D:\TrpgMaps`，或直接解压到 U 盘）。
   ⚠️ 不要解压到 `C:\Program Files` 这类受保护目录 —— 便携版没有安装程序去放开写权限，
   上传底图和保存绘图都会失败。
3. 双击里面的 `TrpgMaps.exe`。
4. 卸载：直接删掉整个文件夹即可（程序不会往其它地方写东西，
   注册表里也不会有记录）。

两种方式的功能完全一样。区别只是：安装版会把卸载信息写进系统、并创建快捷方式；
便携版是全绿的，换台电脑整个文件夹拷过去就能用。

## 三、使用方法

### DM 端（你的电脑）

1. 双击 `TrpgMaps.exe`。程序会**全屏无边框置顶**打开，适合直接投到电视 / 大屏。
2. 左侧侧边栏从上到下是：

   | 按钮 | 作用 |
   | --- | --- |
   | 展开 | 展开 / 收起侧边栏（展开后会显示文字标签） |
   | 地图设置 | 选底图、调网格大小、选网格颜色、旋转角度、导入自己的图片 |
   | 网络 | 查看玩家地址与二维码、设置端口、放行防火墙、管理在线玩家 |
   | 绘图 | 在地图上盖地形 / 实体 / 物品（左上角浮窗，可拖动） |
   | 全屏 | 切换全屏 / 窗口 |
   | 关于 | 作者信息、版本号、检查更新 |

3. 点「网络」，会出现一个**玩家地址**和一个**二维码**。
4. 点「地图设置」→「导入图片」可以换成自己的地图。
   支持 PNG / JPG / GIF / BMP / WebP，直接把图片文件拖进窗口也行。
5. 点「绘图」可以往地图上铺地形（草地、水域、火焰……）、放实体与物品。
   面板里的「清空本类」只清除当前选中那一类，「清空全部」才会清掉所有覆盖层。

### 玩家端（手机 / 平板）

1. 连上**和 DM 同一台路由器**的 Wi-Fi（不是手机流量）。
2. 用相机 / 微信扫 DM 屏幕上那个二维码，或直接在浏览器里输入 DM 端显示的玩家地址
   （形如 `http://192.168.1.100:5000`）。
3. 打开后就能看到地图，DM 端的一切改动都会实时同步过来。
   网页是只读的，玩家不能改动地图。
4. 玩家加入后，会出现在 DM 端「网络」面板的在线列表里。

## 四、连不上？先看这里

手机打不开玩家页面，**九成以上是 Windows 防火墙的问题**，而且症状很有迷惑性：
DM 端一切正常、地址也对、二维码也能扫，手机就是一直转圈打不开。

处理办法：

1. 打开 TrpgMaps 的「网络」面板，看「防火墙：」那一行。
   如果它提示被阻止，直接点下面的 **「放行防火墙（需管理员确认）」** 按钮，
   在弹出的是否允许提示里点「是」，然后重试。
2. 程序目录里有一个 **`放行防火墙.bat`**，右键「以管理员身份运行」也可以（同样会弹一次确认）。
   便携版就在解压出来的文件夹里，安装版在安装目录里。
3. 首次启动时如果 Windows 弹出「是否允许 TrpgMaps 通过防火墙」——
   这个提示框有时会被程序的全屏界面挡住，请**先最小化 / 切出去找一下**，并点「允许」。

> 为什么会被挡：本程序默认全屏置顶，而 Windows 的授权提示是普通窗口，
> 会被压在底下。如果被随手关掉，Windows 会记住一条永久阻止规则，以后再也不会问你。
> 所以程序在启动时会主动检查，被挡就直接提示并提供一键修复。

其它可能原因：

- **手机和电脑不在同一个局域网**（手机开的是流量，或连了访客 Wi-Fi）。
  请确认两边的 IP 前三段一致（比如都是 `192.168.1.x`）。
- **路由器开了「AP 隔离 / 客户端隔离」**，同一 Wi-Fi 下的设备互相不能通信。
  到路由器设置里关掉它，或换一个 Wi-Fi。
- **端口被占用**：到「网络」面板把端口改成别的（比如 5001）再保存重开。
- **校园网 / 公司网**：这类网络通常禁止设备之间互访，建议自己开热点。

## 五、更新

- 程序启动几秒后会自动检查一次是否有新版本；也可以点侧边栏最底部的
  **「关于」→「检查更新」** 手动检查。
- 发现有新版本时会弹窗，三个选项：
  - **更新** —— 自动下载并安装（便携版只替换程序文件；安装版还会顺带修正注册信息）；
  - **下次一定** —— 这次先不更新，下次启动还会提醒；
  - **不再提示** —— 不再提醒这个版本，后续更新的版本仍会提示。
- 更新源优先使用 **Gitee**，失败时自动切换到 **GitHub**。
- 也可以随时到仓库的 Releases 页面手动下载安装包覆盖安装。

## 六、常见问题

**Q：程序打不开 / 一闪而过？**
A：看程序目录下的 `app.log`，里面记录了失败原因。

**Q：地图是黑的？**
A：v1.0.0 起已支持 WebP。如果你用的是自己导入的图片，请确认扩展名是
`.png / .jpg / .jpeg / .gif / .bmp / .webp` 之一。

**Q：网格和底图对不齐？**
A：网格的格子大小是按厘米算的，与实际打印尺寸无关。
在「地图设置」里拖动滑块调整「每格厘米数」即可让格子对上底图上的格子。

**Q：能同时给多个人用吗？**
A：可以。局域网内任意数量的手机 / 平板都能同时连上来看同一张地图。

**Q：会把我的地图上传到网上吗？**
A：不会。程序没有任何联网上传行为，地图只在你自己的电脑上。
唯一的网络请求是「检查更新」。

**Q：卸载后我的地图和绘图还在吗？**
A：安装版的卸载程序会问你是否保留 `maps` 目录与 `drawing.json`，
选择保留就会留在安装目录里。便携版删除文件夹即可，注意先备份。
